# Radio frequency electric circuit theory and calculations

# https://daniel-chermetz.github.io/rf-circuit-design-storybook/

Try in the browser through the link above

I wrote a radio frequency circuit calculator as part of the learning process of RF circuit design.

AI (Gemini 3.8 Flash) later built a story book UI around my calculator code, with each page containing an interactive demo and details the applicable theory around the presented demo (I wrote the theory associated with each story book page as a list of bullet points in the prompt, and AI has translated and expanded my ideas into nice writing with the math properly rendered through markup).
