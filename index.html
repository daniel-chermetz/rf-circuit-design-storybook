Calculation review & model limits

The supplied JS file is imported unchanged. The UI converts input units, sets globalThis.frequency, load_impedance, and generator, then calls its functions again. Its original demonstration also executes once on import.

  • getTLWaveParams implements γ = √[(R + jωL)(G + jωC)] and Z₀ = (R + jωL)/γ for passive RLGC inputs at positive frequency. γ = α + jβ; α is in Np/m and β in rad/m.
  • getTLRefelectionCoefficient (spelling preserved) computes the voltage reflection coefficient (ZL − Z₀)/(ZL + Z₀), including complex Z₀. On a lossy line this is not a power-wave reflection coefficient.
  • The functions ending in lossless_TL require R = G = 0. For a lossy line Γ(d) = ΓL exp(−2γd), and Z(d) uses complex Z₀. Those effects are absent from the lossless helpers, so the UI does not use them for nonzero R or G.
  • With time dependence exp(jωt), the supplied signs are consistent for positive distance toward the generator: Γ(d) = ΓL exp(−j2βd) and V(d) = V₀⁺[exp(jβd) + ΓL exp(−jβd)]. The generator uses a Thévenin voltage divider.
  • z_magnitude = zl.magnitude * z0_magnitude converts normalized magnitude to ohms. The UI passes the current z0_magnitude as the fourth argument to get_swr_circle_lossless_TL, followed by beta.
  • The circle routine samples about 36 positions per half wavelength and may add a voltage maximum. Its grid can miss the exact minimum and sharp peaks. Repeated periods in the distance plots reuse these returned samples; an exact endpoint comes from the impedance/voltage helpers. The locus uses equal units on both axes.
  • The utilities do not guard against division by zero, overflow, ideal open circuits, or pure-reactive resonances. This UI requires finite passive inputs, positive frequency/L/C, and a positive load resistance for the downstream plots. Purely reactive loads still show wave parameters, reflection, and infinite lossless SWR.
  • The normalized-impedance locus is a circle for finite SWR, with center (S + 1/S)/2 and radius (S − 1/S)/2. Constant |Γ| is a circle centered at zero in the reflection plane.
  • The source uses 3 × 10⁸ m/s for c. Its velocity fraction is approximate. A tiny nonzero α for R = G = 0 is floating-point roundoff. The RLGC model alone does not establish that arbitrary parameters describe a realizable cable.
