Prerequisite Required

No S-parameters Available

This amplifier design wizard requires measured or simulated 2-port S-parameters (S11, S12, S21, S22) to compute the input and output reflection coefficients (Γin, Γout) and matching network impedances (Zin, Zout).

If you have transistor datasheet values or network analyzer measurements, return to the first step and select Yes.
